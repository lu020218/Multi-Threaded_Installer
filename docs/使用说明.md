## 快速入门

### 1. 准备工作

确保已安装以下软件：
- Rust 1.75 或更高版本
- Windows 10 SDK

### 2. 构建工具

```bash
cd rust-installer
cargo build --release
```

### 3. 创建安装程序

打包器会直接生成一个可执行的安装程序（.exe），用户双击即可运行安装：

```bash
# 准备应用程序文件夹
mkdir my-app
# 将应用程序文件复制到 my-app 文件夹

# 创建配置文件 packager.json
echo '{"application_name": "我的应用", "version": "1.0.0"}' > my-app/packager.json

# 打包生成安装程序
./target/release/packager --input ./my-app --output ./MyApp-Setup.exe
```

### 4. 运行安装程序

生成的安装程序是一个独立的可执行文件，用户可以直接双击运行：

```bash
# 双击运行或命令行执行
./MyApp-Setup.exe
```

安装程序会自动：
- 显示图形化安装界面（如果有 WebView2）
- 或回退到命令行安装模式

## 创建安装程序

### 工作原理

打包器（packager）的工作流程：

1. 扫描输入目录中的所有文件
2. 使用 Zstd 或 LZMA 算法压缩文件
3. 生成安装包元数据（TOC、Metadata）
4. 将压缩数据和 UI 资源嵌入到安装器模板中
5. 输出一个独立的可执行安装程序（.exe）

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   应用程序文件   │ --> │     打包器      │ --> │  安装程序.exe   │
│   + 配置文件    │     │   (packager)    │     │  (可直接运行)   │
│   + UI资源      │     │                 │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

### 基本用法

```bash
packager --input <输入目录> --output <安装程序.exe>
```

### 示例

```bash
# 基本打包 - 生成可执行安装程序
packager --input ./my-app --output ./MyApp-Setup.exe

# 指定配置文件
packager --input ./my-app --output ./MyApp-Setup.exe --config ./custom-config.json

# 包含自定义 UI 界面
packager --input ./my-app --output ./MyApp-Setup.exe --ui-resources ./my-ui

# 高压缩率打包（文件更小，打包更慢）
packager --input ./my-app --output ./MyApp-Setup.exe \
    --compression-algorithm zstd \
    --compression-level 19

# 显示详细输出
packager --input ./my-app --output ./MyApp-Setup.exe --verbose
```

### 输入目录结构示例

```
my-app/
├── packager.json          # 配置文件（必需）
├── myapp.exe              # 主程序
├── myapp.dll              # 依赖库
├── resources/             # 资源文件
│   ├── images/
│   └── data/
├── plugins/               # 插件目录（可配置安装到其他位置）
└── ui/                    # 自定义安装界面（可选）
    ├── index.html
    ├── styles/
    └── locales/
```

## 运行安装程序

### GUI 模式

生成的安装程序默认以 GUI 模式运行（需要 WebView2）：

```bash
# 直接双击运行，或命令行执行
MyApp-Setup.exe
```

GUI 安装器提供：
- 欢迎页面（显示应用名称、版本、许可协议）
- 安装目录选择页面
- 安装进度显示
- 完成页面（可选启动应用程序）

### 命令行模式

安装程序也支持命令行参数，适用于自动化部署：

```bash
# 指定安装目录
MyApp-Setup.exe --install-dir "D:\Apps\MyApp"

# 不创建快捷方式
MyApp-Setup.exe --no-shortcuts

# 不写入注册表
MyApp-Setup.exe --no-registry
```

### 静默安装

适用于企业部署和自动化场景：

```bash
# 静默安装（使用默认设置，无任何界面）
MyApp-Setup.exe --silent

# 静默安装到指定目录
MyApp-Setup.exe --silent --install-dir "C:\Program Files\MyApp"

# 完整静默安装示例
MyApp-Setup.exe --silent \
    --install-dir "D:\Apps\MyApp" \
    --no-shortcuts \
    --no-registry

# 检查安装结果
MyApp-Setup.exe --silent && echo "安装成功" || echo "安装失败"
```

### 退出代码

| 代码 | 含义 |
|------|------|
| 0 | 安装成功 |
| 1 | 一般错误 |
| 2 | 磁盘空间不足 |
| 3 | 权限不足 |
| 4 | 安装包验证失败 |

### 卸载

安装完成后，会在安装目录生成卸载程序：

```bash
# 使用安装目录中的卸载程序
"C:\Program Files\MyApp\uninstall.exe"

# 或通过 Windows 设置 -> 应用 -> 已安装的应用 进行卸载
```

## 配置文件详解

配置文件使用 JSON 格式，文件名为 `packager.json`，放在输入目录中。

### 最小配置

```json
{
  "application_name": "我的应用",
  "version": "1.0.0"
}
```

### 完整配置示例

```json
{
  "application_name": "我的桌面应用",
  "version": "2.1.0",
  "default_install_dir": "%ProgramFiles%\\MyCompany\\MyApp",
  "vendor": "我的公司",
  "license_text": "MIT 许可证...",
  "icon_path": "resources/app.ico",
  "compression_algorithm": "Zstd",
  "compression_level": 9,
  "block_size": 8388608,
  "require_admin": true,
  "auto_startup": false,
  "desktop_icons": true,
  "min_windows_version": {
    "major": 10,
    "minor": 0,
    "build": 19041
  },
  "process_name": "myapp.exe",
  "folder_targets": [
    {
      "folder_name": "plugins",
      "target_directory": "%AppData%\\MyApp\\plugins"
    },
    {
      "folder_name": "config",
      "target_directory": "%LocalAppData%\\MyApp\\config"
    }
  ],
  "registry_entries": [
    {
      "path": "HKEY_CURRENT_USER\\Software\\MyCompany\\MyApp",
      "key": "InstallDir",
      "value": "%InstallDir%",
      "value_type": "String"
    },
    {
      "path": "HKEY_CURRENT_USER\\Software\\MyCompany\\MyApp",
      "key": "Version",
      "value": "2.1.0",
      "value_type": "String"
    }
  ],
  "ui_resources_dir": "./ui",
  "thread_count": 4
}
```

### 配置项说明

#### 基本信息

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `application_name` | 字符串 | 是 | - | 应用程序显示名称 |
| `version` | 字符串 | 是 | - | 版本号（语义化版本） |
| `default_install_dir` | 字符串 | 否 | `%ProgramFiles%` | 默认安装目录 |
| `vendor` | 字符串 | 否 | - | 开发商/发布者名称 |
| `license_text` | 字符串 | 否 | - | 许可协议文本 |
| `icon_path` | 字符串 | 否 | - | 应用程序图标路径 |

#### 压缩设置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `compression_algorithm` | 字符串 | `Zstd` | 压缩算法：`Zstd` 或 `Lzma` |
| `compression_level` | 数字 | `3` | 压缩级别（Zstd: 1-22, LZMA: 0-9） |
| `block_size` | 数字 | `4194304` | 压缩块大小（字节），默认 4MB |
| `thread_count` | 数字 | CPU核心数 | 并行处理线程数 |

#### 安装选项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `require_admin` | 布尔 | `false` | 是否需要管理员权限 |
| `auto_startup` | 布尔 | `false` | 是否添加到开机启动 |
| `desktop_icons` | 布尔 | `false` | 是否创建桌面快捷方式 |
| `process_name` | 字符串 | - | 安装前检查的进程名 |

#### Windows 版本要求

```json
{
  "min_windows_version": {
    "major": 10,
    "minor": 0,
    "build": 19041
  }
}
```

#### 文件夹映射

将特定文件夹安装到不同位置：

```json
{
  "folder_targets": [
    {
      "folder_name": "plugins",
      "target_directory": "%AppData%\\MyApp\\plugins"
    }
  ]
}
```

支持的环境变量：
- `%ProgramFiles%` - Program Files 目录
- `%AppData%` - 用户应用数据目录
- `%LocalAppData%` - 用户本地应用数据目录
- `%InstallDir%` - 安装目录

#### 注册表项

```json
{
  "registry_entries": [
    {
      "path": "HKEY_CURRENT_USER\\Software\\MyApp",
      "key": "InstallDir",
      "value": "%InstallDir%",
      "value_type": "String"
    }
  ]
}
```

支持的值类型：
- `String` - 字符串
- `Dword` - 32位整数
- `ExpandString` - 可展开字符串

## 自定义安装界面

安装器 GUI 使用 HTML/CSS/JavaScript 构建，可以完全自定义品牌和样式。

### 工作原理

自定义 UI 的工作流程：

1. **打包时**：打包器将自定义 UI 资源（HTML/CSS/JS）压缩并嵌入到安装包中
2. **运行时**：安装程序检测到包中有自定义 UI 资源，将其提取到临时目录
3. **加载**：通过自定义协议（`customui://`）加载提取的 UI 资源

这意味着您可以自定义 UI 而**无需重新编译安装器模板**，只需重新打包即可。

### UI 资源目录结构

```
ui/
├── index.html          # 主 HTML 文件（必需）
├── styles/
│   └── main.css        # 样式表
├── scripts/
│   └── main.js         # JavaScript 逻辑
└── locales/
    ├── en-US.json      # 英文翻译
    └── zh-CN.json      # 中文翻译
```

### 自定义步骤

1. 复制默认 UI 资源作为模板：
   ```bash
   cp -r rust-installer/examples/ui-template ./my-custom-ui
   ```

2. 修改 HTML、CSS 和 JavaScript 以匹配您的品牌

3. 在配置文件中指定自定义 UI：
   ```json
   {
     "ui_resources_dir": "./my-custom-ui"
   }
   ```

4. 重新打包生成安装程序（无需重新编译安装器模板）：
   ```bash
   packager --input ./my-app --output ./MyApp-Setup.exe
   ```

> **注意**：如果不指定 `ui_resources_dir`，安装程序将使用编译时嵌入的默认 UI。

### 可用的 Tauri 命令

在 JavaScript 中可以调用以下命令与安装器核心交互：

```javascript
const { invoke } = window.__TAURI__.core;

// 获取安装包元数据
const metadata = await invoke('get_metadata', { packagePath: './package.mti' });

// 检查系统要求
const result = await invoke('check_prerequisites', { 
  packagePath: './package.mti',
  installDir: 'C:\\Program Files\\MyApp' 
});

// 开始安装
await invoke('start_install', { 
  request: { 
    package_path: './package.mti',
    install_dir: 'C:\\Program Files\\MyApp',
    create_shortcuts: true,
    auto_startup: false
  } 
});

// 取消安装
await invoke('cancel_install');

// 打开目录选择对话框
const dir = await invoke('browse_directory', { 
  defaultPath: 'C:\\Program Files' 
});

// 获取系统语言
const locale = await invoke('get_system_locale');

// 获取翻译文本
const translations = await invoke('get_translations', { locale: 'zh-CN' });

// 窗口控制（用于自定义标题栏）
await invoke('minimize_window');  // 最小化窗口
await invoke('close_window');     // 关闭窗口
```

#### JavaScript 实现

```javascript
// 设置窗口控制按钮
function setupWindowControls() {
    const minimizeBtn = document.getElementById('titlebar-minimize');
    const closeBtn = document.getElementById('titlebar-close');
    
    if (minimizeBtn) {
        minimizeBtn.addEventListener('click', async (e) => {
            e.preventDefault();
            e.stopPropagation();
            await invoke('minimize_window');
        });
    }
    
    if (closeBtn) {
        closeBtn.addEventListener('click', async (e) => {
            e.preventDefault();
            e.stopPropagation();
            await invoke('close_window');
        });
    }
}

// 在 DOM 加载完成后调用
document.addEventListener('DOMContentLoaded', () => {
    setupWindowControls();
});
```

> **注意**: 使用 `invoke('minimize_window')` 和 `invoke('close_window')` 命令比直接使用 Tauri JavaScript API 更可靠，因为它们通过 Rust 后端实现，避免了 Tauri 2.0 API 的兼容性问题。

## 常见问题

### Q: 如何减小安装程序体积？

A: 可以通过以下方式减小体积：
1. 使用更高的压缩级别：`--compression-level 19`
2. 排除不必要的文件
3. 对于文本文件较多的项目，LZMA 可能比 Zstd 压缩率更高

### Q: 安装时提示需要管理员权限？

A: 如果安装到 `Program Files` 等系统目录，需要管理员权限。可以：
1. 以管理员身份运行安装程序
2. 选择用户目录作为安装位置
3. 在配置中设置 `"require_admin": true` 自动请求提权

### Q: 如何实现自动更新？

A: 可以通过以下方式实现：
1. 在应用程序中检测新版本
2. 下载新的安装程序
3. 使用静默安装模式更新：`MyApp-Setup.exe --silent`

### Q: GUI 安装界面无法显示？

A: 请检查：
1. 是否安装了 WebView2 运行时
2. Windows 版本是否满足要求（Windows 10 1903+）
3. 安装程序会自动回退到命令行模式

### Q: 如何调试安装过程？

A: 使用 `--verbose` 参数查看详细日志：
```bash
MyApp-Setup.exe --verbose
```

日志文件位置：
- GUI 模式：`%TEMP%\installer.log`
- CLI 模式：标准输出

### Q: 支持哪些压缩算法？

A: 支持两种压缩算法：
- **Zstd**（默认）：压缩/解压速度快，适合大多数场景
- **LZMA**：压缩率更高，但速度较慢，适合对体积敏感的场景

### Q: 如何处理安装失败？

A: 安装程序具有自动回滚功能：
1. 安装失败时会自动删除已安装的文件
2. 清理已创建的注册表项
3. 删除已创建的快捷方式

### Q: 如何为企业批量部署？

A: 使用静默安装模式：
```bash
# 批量部署脚本示例
MyApp-Setup.exe --silent --install-dir "C:\Program Files\MyApp"
if %ERRORLEVEL% EQU 0 (
    echo 安装成功
) else (
    echo 安装失败，错误代码: %ERRORLEVEL%
)
```

### Q: 安装程序的工作原理是什么？

A: 安装程序是一个自解压的可执行文件：
1. 打包器将应用程序文件压缩并嵌入到安装器模板中
2. 运行时，安装程序从自身提取压缩数据
3. 解压文件到目标目录
4. 配置注册表、快捷方式等
