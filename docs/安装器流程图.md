# 安装器流程图

本文档按当前代码重新梳理安装器、卸载器与 GUI/静默入口的主流程。

主要入口：
- 安装器入口：[src/installer/installer_main.cpp](../src/installer/installer_main.cpp)
- 卸载器入口：[src/installer/uninstaller_main.cpp](../src/installer/uninstaller_main.cpp)
- 启动分发：[src/installer/launch_support.cpp](../src/installer/launch_support.cpp)
- 安装服务编排：[src/installer/install_service.cpp](../src/installer/install_service.cpp)
- 卸载执行：[src/installer/uninstall_manager.cpp](../src/installer/uninstall_manager.cpp)

## 总体启动流程

```mermaid
flowchart TD
    A[启动 installer.exe 或 uninstall.exe] --> B[BuildLaunchContextFromCommandLine]
    B --> C[解析命令行参数]
    C --> D{是否 --help}
    D -->|是| D1[输出安装器或卸载器帮助并退出]
    D -->|否| E{是否 --cleanup-self}
    E -->|是| E1[RunCleanupHelper 等待父进程后清理 exe、manifest、root]
    E -->|否| F{LaunchBinary 与 --silent}
    F -->|installer + GUI| G[RunGuiInstallLikeMode]
    F -->|installer + silent| H[RunSilentInstallLikeMode]
    F -->|uninstaller + GUI| I[RunGuiUninstallMode]
    F -->|uninstaller + silent| J[RunSilentUninstallMode]
```

## GUI 安装流程

```mermaid
flowchart TD
    A[RunGuiInstallLikeMode] --> B[初始化 COM 与日志]
    B --> C[解析并校验 embedded metadata]
    C --> D{metadata 有效?}
    D -->|否| D1[显示错误并退出]
    D -->|是| E[通过 cleanup.onUpgrade.installRoots 发现旧实例]
    E --> G[构造 InstallConfig]
    G --> H[准备并校验 GUI 资源]
    H --> I[创建 GUIManager 窗口]
    I --> J[用户选择安装路径、组件、开机启动、桌面图标等]
    J --> K[InstallationWorker 后台线程]
    K --> L[构造 InstallServiceOptions 与 GUI 回调]
    L --> M[ExecuteInstallService]
    M --> N[PostMessage 更新进度与完成状态]
```

## 静默安装流程

```mermaid
flowchart TD
    A[RunSilentInstallLikeMode] --> B[解析并校验 embedded metadata]
    B --> C{metadata 有效?}
    C -->|否| C1[返回 INSTALLER_EXIT_FAILED]
    C -->|是| D[发现已安装实例]
    D --> E{已安装且当前版本不高于旧版本?}
    E -->|是| E1[拒绝静默安装]
    E -->|否| F[解析安装路径]
    F --> G{命令行指定 --install-dir?}
    G -->|是| H[使用指定路径]
    G -->|否| I{发现旧实例?}
    I -->|是| I1[使用旧实例 installDir]
    I -->|否| I2[展开 install.defaultDir]
    H --> L[构造 InstallServiceOptions]
    I1 --> L
    I2 --> L
    L --> M[ExecuteInstallService]
    M --> N[按 success、cancelled、rebootRequired 映射退出码]
```

## 安装服务主流程

```mermaid
flowchart TD
    A[ExecuteInstallService] --> B[Preparing 状态]
    B --> C{是否已取消?}
    C -->|是| C1[标记 Cancelled 并释放资源]
    C -->|否| D[BuildInstallExecutionPlan]
    D --> E{计划构建成功?}
    E -->|否| E1[写 install_failed 并返回失败]
    E -->|是| F[ExecuteInstallPrecheck]
    F --> G{预检通过?}
    G -->|否| G1[写 install_failed、释放 mutex、返回失败]
    G -->|是| H[ExecuteInstallCleanup]
    H --> I{旧安装清理通过?}
    I -->|否| I1[写 install_failed、释放 mutex、返回失败]
    I -->|是| J[写核心 installInfo state=installing]
    J --> K[ExecuteInstallExecution]
    K --> L{文件与组件安装成功?}
    L -->|否| L1[写 install_failed、释放 mutex、返回失败]
    L -->|是| M[ExecuteInstallFinalization]
    M --> N{收尾成功?}
    N -->|否| N1[写 install_failed、释放 mutex、返回失败]
    N -->|是| O{是否有可选组件失败?}
    O -->|是| O1[整体返回失败并报告组件错误]
    O -->|否| P{是否需要重启替换锁定文件?}
    P -->|是| P1[返回 RebootRequired]
    P -->|否| Q[返回 Completed success=true]
```

## 安装计划构建

```mermaid
flowchart TD
    A[BuildInstallExecutionPlan] --> B[解析 appId 与 directoryName]
    B --> C[resolveInstalledInstanceFromInstallRoots]
    C --> D{发现旧实例?}
    D -->|是| D1[记录 previousManifest 与 previousInstallDir]
    D -->|否| D2[FreshInstall]
    D1 --> E[ResolveInstallPathDecision]
    D2 --> E
    E --> F{发现旧实例?}
    F -->|是| F1[mode=OverwriteInstall cleanupTargetInstallRoot=旧目录]
    F -->|否| F2[mode=FreshInstall resolvedInstallRoot=请求路径]
    F1 --> G[收集旧桌面快捷方式候选]
    F2 --> G
    G --> H[构建组件选择计划]
    H --> I[必选组件 + 默认组件或命令行选择]
    I --> J[递归加入依赖并检查循环依赖]
    J --> K[合并组件 folders、killProcesses、registry、startup、shortcut]
    K --> L[确定 selectedEmbeddedFolders 与 totalInstallBytes]
```

## 预检与升级清理

```mermaid
flowchart TD
    A[ExecuteInstallPrecheck] --> B[检查磁盘空间]
    B --> C[检查最低 Windows 版本]
    C --> D[根据 appName 与 killProcesses 结束运行进程]
    D --> E{是否取消?}
    E -->|是| E1[返回 cancelled]
    E -->|否| F{install.useMutex?}
    F -->|是| F1[获取安装 mutex]
    F -->|否| G[预检完成]
    F1 --> G

    H[ExecuteInstallCleanup] --> I{是否有旧安装?}
    I -->|否| I1[跳过清理]
    I -->|是| J{新旧安装根目录相同?}
    J -->|不同| K[cleanupPreviousInstallForUpgrade 清理旧目录与旧 manifest 记录]
    J -->|相同| L[复用原安装目录]
    K --> M[cleanupUpgradeSystemArtifacts 清理 onUpgrade 注册表、卸载项、快捷方式、启动项、额外路径]
    L --> M
```

## 文件与组件安装

```mermaid
flowchart TD
    A[ExecuteInstallExecution] --> B[计算解压阶段权重]
    B --> C{是否只安装组件且无 embedded folder?}
    C -->|是| C1[跳过包内文件解压]
    C -->|否| D[FolderPayloadReader 读取 embedded 或 external payload]
    D --> E[RunParallelInstall 多线程解压]
    E --> F[按 mapping.targetPath 解析最终落点]
    F --> G[解压 folder payload 并处理锁定文件替换]
    G --> H{解压成功?}
    H -->|否| H1[返回错误、取消或 reboot 信息]
    H -->|是| I[执行组件安装]
    C1 --> I
    I --> J{组件 source.type}
    J -->|embedded| J1[无额外进程，仅依赖已解压 folder]
    J -->|local| J2[执行本地 installer，可记录 uninstallCommand]
    J -->|download| J3[HTTPS 下载、校验 SHA256、执行 installer、可记录 uninstallCommand]
    J1 --> K[合并组件注册表、启动项、快捷方式]
    J2 --> K
    J3 --> K
    K --> L{必选组件失败?}
    L -->|是| L1[安装失败]
    L -->|否| M[可选组件失败则记录，安装阶段继续]
```

## 安装收尾

```mermaid
flowchart TD
    A[ExecuteInstallFinalization] --> B{是否 applyRegistryBeforeFinalize?}
    B -->|是| B1[先写 lifecycle.registry.onInstall 与组件 registry]
    B -->|否| C[解析语言与桌面快捷方式显示名]
    B1 --> C
    C --> D[删除旧版桌面与开始菜单快捷方式候选]
    D --> E[查找主程序 exe]
    E --> F[按配置创建开机启动项]
    F --> G[按配置创建桌面与开始菜单快捷方式]
    G --> H[收集 installedFiles]
    H --> I[从资源提取 UNINSTALLER_EXE 到 installRoot/uninstall.exe]
    I --> J[写 install.manifest.json]
    J --> K{是否 applyRegistryAfterInstall?}
    K -->|是| K1[安装后写注册表]
    K -->|否| L[写系统卸载注册表项]
    K1 --> L
    L --> M[写核心 installInfo state=installed]
    M --> N[收尾完成]
```

## 卸载流程

```mermaid
flowchart TD
    A[RunGuiUninstallMode 或 RunSilentUninstallMode] --> B[尝试解析 embedded metadata]
    B --> C[ResolveUninstallManifestPath]
    C --> D{当前 exe 同目录 manifest 存在?}
    D -->|是| D1[使用本地 install.manifest.json]
    D -->|否| E{metadata 有效且能从 installRoots 发现旧实例?}
    E -->|是| E1[使用旧实例 manifestPath]
    E -->|否| E2[报错 Manifest not found]
    D1 --> F[检查管理员权限]
    E1 --> F
    F --> G{非管理员?}
    G -->|是| G1[尝试管理员重启；失败返回 ADMIN_REQUIRED]
    G -->|否| H{GUI 还是静默}
    H -->|GUI| H1[UninstallWorker 后台执行并回传进度]
    H -->|静默| H2[直接调用 uninstallFromManifest]
    H1 --> I[uninstallFromManifest]
    H2 --> I
```

## manifest 卸载执行

```mermaid
flowchart TD
    A[uninstallFromManifest] --> B[读取 install.manifest.json]
    B --> C[解析 appId、displayName、installDir、uninstallPath、files、cleanupRoots]
    C --> D[解析 installInfo、lifecycleUninstallCleanup、componentActions、registry]
    D --> E[计算进度工作量]
    E --> F[结束 killProcesses 与 onUninstall.processes]
    F --> G[写核心 installInfo state=uninstalling]
    G --> H[回放 componentActions 中的卸载命令]
    H --> I[删除开机启动项]
    I --> J[删除桌面与开始菜单快捷方式]
    J --> K[删除安装期 registry values]
    K --> L[删除 onUninstall.registry.legacyKeys]
    L --> M[删除卸载注册表项]
    M --> N[删除 uninstall.exe 如果不是当前进程]
    N --> O[删除 manifest.files 中记录的文件]
    O --> P[扫描 cleanupRoots，删除忽略文件与空目录]
    P --> Q[执行 onUninstall.paths 规则]
    Q --> R[写核心 installInfo state=uninstalled]
    R --> S[删除 install.manifest.json]
    S --> T[尝试删除空 install root]
    T --> U{当前进程是 uninstall.exe?}
    U -->|是| U1[scheduleSelfDeleteImmediate 或 scheduleSelfDelete]
    U -->|否| V[卸载完成]
    U1 --> V
```

## 关键规则

- 启动模式只由入口二进制与 `--silent` 决定：`installer.exe` 进入安装，`uninstaller.exe` 进入卸载。
- `--cleanup-self` 是内部清理辅助路径，不参与正常安装或卸载模式选择。
- GUI 安装会先打开窗口，再由 `InstallationWorker` 调用统一安装服务；静默安装直接调用统一安装服务。
- 覆盖安装判定来自 `cleanup.onUpgrade.installRoots` 发现的已安装实例；发现旧实例时会进入 `OverwriteInstall` 并优先复用旧安装目录。
- 静默安装如果发现旧实例，只有当前包版本高于已安装版本才允许继续。
- 安装包内目录最终落点由 metadata 中的 `layout.folders[].target` 固化，安装器不再推导旧式目录类型。
- 组件选择会自动包含 required 组件、默认组件或命令行选择组件，并递归加入依赖。
- 必选组件失败会中止安装；可选组件失败会继续执行，但最终结果标记为失败并返回组件错误。
- 若文件替换需要重启，安装服务返回 `RebootRequired`，不把结果当作普通成功。
