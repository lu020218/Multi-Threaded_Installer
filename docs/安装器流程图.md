# 安装器流程图

本文档描述当前 manifest 驱动的安装、覆盖/升级、卸载流程。

「值/逻辑各归其位」重构后：内嵌的 package manifest 只携带 **身份 + 载荷 + 钩子**；安装行为默认值、清理规则、注册表、系统卸载入口由引擎写死；跨版本兼容走引擎迁移表（`src/installer/migration`）。配置写法见 [USER_GUIDE](USER_GUIDE.md)。

## 启动分发

```mermaid
flowchart TD
    A["启动 installer.exe / uninstall.exe"] --> B["BuildLaunchContextFromCommandLine"]
    B --> C{"隐藏 worker 参数"}
    C -->|清理 worker| C1["执行同步清理任务"]
    C -->|否| D{"uninstall 模式"}
    D -->|是| E["RunGui / RunSilentUninstallMode"]
    D -->|否| F{"--silent"}
    F -->|是| F1["RunSilentInstallLikeMode"]
    F -->|否| F2["RunGuiInstallLikeMode"]
```

## 读取内嵌数据

```mermaid
flowchart TD
    A["定位自身 exe"] --> B["从尾部读 DataLocator（校验 magic）"]
    B --> C["拿到 metadata / data 偏移与大小"]
    C --> D["反序列化 package manifest（PMF2）"]
    D --> E["投影为运行期 ExtendedInstallationMetadata"]
    E --> F["GUI 启动可跳过 fileIndex 加速"]
    G["FindResource RES_ZIP（PE 资源）"] --> H["内存展开 GUI 皮肤（DuiLib）"]
```

## 安装计划

```mermaid
flowchart TD
    A["运行期 metadata（身份/载荷/钩子）"] --> B{"--upgrade"}
    B -->|是| C["从固定注册表/install-state.json 探测已装目录"]
    C --> D{"探测成功"}
    D -->|否| D1["升级失败退出"]
    D -->|是| E["固定旧安装目录为升级目标"]
    B -->|否| F["按 CLI/GUI/app.defaultDir 解析目标目录"]
    F --> G["探测是否已存在安装（覆盖安装判定）"]
    E --> H["BuildInstallExecutionPlan"]
    G --> H
    H --> I["effectiveRegistry/killProcesses/auto/desktop 由引擎默认 + 产品名派生"]
```

## 安装执行

```mermaid
flowchart TD
    A["准备安装"] --> B["写 installState = installing"]
    B --> C["预检查、磁盘检查、互斥量"]
    C --> D["运行 preInstall hook（注入 INSTALL_DIR/VERSION）"]
    D --> D2{"hook 失败"}
    D2 -->|onFailure=abort| D3["中止退出（解压前，无需回滚）"]
    D2 -->|继续| E{"存在旧版本"}
    E -->|是| F["按旧 manifest files 清理旧文件 + 运行迁移表 RunPending"]
    E -->|否| G["跳过旧版本清理"]
    F --> H["解压释放 payload 到各 target"]
    G --> H
    H --> I["写产品注册表 + 系统卸载入口"]
    I --> J["创建快捷方式 / 开机自启 / 释放 uninstall.exe"]
    J --> K["写 installState = installed"]
    K --> L["写本地 install.manifest.json 快照（slim cleanup 账本）"]
    L --> M["运行 postInstall hook"]
    M --> M2{"hook 失败且 onFailure=abort"}
    M2 -->|是| M3["RollbackInstalledArtifacts（删文件/注册表/卸载入口/installState）"]
    M2 -->|否| N["安装成功"]
```

安装失败路径写 `installState = install_failed` 后返回失败。preInstall+abort 在解压前发生，无需回滚；postInstall+abort 触发完整回滚。

## Payload 释放

```mermaid
flowchart TD
    A["读取 manifest.payload.folders"] --> B["解析每文件夹 target（展开环境变量）"]
    B --> C{"分帧(framed) 且有旧指纹"}
    C -->|是| D["按文件指纹跳过未变文件（增量，不解压不重写）"]
    C -->|否| E["解压整流到目标目录"]
    D --> F["记录成功释放文件列表"]
    E --> F
    F --> G["收尾写入 manifest payload.files + fileFingerprints"]
```

释放成功文件列表直接用于 `install.manifest.json`，避免收尾再次扫描整个安装目录。

## 本地 manifest 快照

```mermaid
flowchart TD
    A["安装完成"] --> B["写 identity（appId/appName/version/publisher）"]
    B --> C["写 installDir / files / fileFingerprints / cleanupRoots"]
    C --> D["写 killProcesses"]
    D --> E["写 cleanup 账本：processes / shortcuts / startup / uninstallEntries"]
    E --> F["写实际 autoStartup / desktopIcon 选择 + uninstallPath"]
```

manifest VERSION = 3（slim）。卸载只消费该快照；注册表与系统卸载入口的清理由引擎按产品名写死，不再记录注册表/路径名单。

## 卸载流程

```mermaid
flowchart TD
    A["运行 uninstall 模式"] --> B["ResolveUninstallContext"]
    B --> C{"显式 --uninstall-manifest 或本地 manifest 可读"}
    C -->|是| D["读取 install.manifest.json 快照"]
    D --> E{"ValidateUninstallManifest 必需字段完整"}
    E -->|否| E1["卸载失败，不做目录级 fallback"]
    E -->|是| F["按 manifest 执行卸载"]
    C -->|否| G["从固定注册表/install-state.json 探测安装目录"]
    G --> H{"目录安全可降级"}
    H -->|否| H1["卸载失败或仅清理可确认痕迹"]
    H -->|是| I["安全降级卸载"]
```

## Manifest 卸载

```mermaid
flowchart TD
    A["关闭 killProcesses 进程"] --> B["按 manifest files 多线程同步删除文件"]
    B --> C["清理 cleanupRoots 下的空目录"]
    C --> D["删除产品注册表键 + install-state.json"]
    D --> E["清理快捷方式 / 开机自启"]
    E --> F["按产品名删除系统卸载入口（+ 迁移表声明的 legacy 入口）"]
    F --> G["调度 uninstall.exe 自删除"]
```

卸载完成前同步等待清理结束，不使用后台 detached 删除。
