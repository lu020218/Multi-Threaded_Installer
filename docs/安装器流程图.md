# 安装器流程图

本文档按当前代码梳理安装器、卸载器与 GUI/静默入口的主流程，重点覆盖近期优化后的旧版本清理、卸载清理和安装 manifest 文件列表生成逻辑。

主要入口：
- 安装器入口：[src/installer/installer_main.cpp](../src/installer/installer_main.cpp)
- 卸载器入口：[src/installer/uninstaller_main.cpp](../src/installer/uninstaller_main.cpp)
- 启动分发：[src/installer/launch_support.cpp](../src/installer/launch_support.cpp)
- 安装服务编排：[src/installer/install_service.cpp](../src/installer/install_service.cpp)
- 卸载执行：[src/installer/uninstall_manager.cpp](../src/installer/uninstall_manager.cpp)

## 总体启动流程

```mermaid
flowchart TD
    A["启动 installer.exe 或 uninstaller.exe"] --> B["BuildLaunchContextFromCommandLine"]
    B --> C["解析命令行参数"]
    C --> D{"是否 --help"}
    D -->|是| D1["输出帮助并退出"]
    D -->|否| E{"是否内部 worker 参数"}
    E -->|--cleanup-self| E1["RunCleanupHelper 等待父进程后清理 exe、manifest、root"]
    E -->|--upgrade-cleanup-worker| E2["执行升级清理 worker"]
    E -->|--uninstall-cleanup-worker| E4["执行卸载清理 worker"]
    E -->|否| F{"入口二进制与 --silent"}
    F -->|installer + GUI| G["RunGuiInstallLikeMode"]
    F -->|installer + silent| H["RunSilentInstallLikeMode"]
    F -->|uninstaller + GUI| I["RunGuiUninstallMode"]
    F -->|uninstaller + silent| J["RunSilentUninstallMode"]
```

## GUI 安装流程

```mermaid
flowchart TD
    A["RunGuiInstallLikeMode"] --> B["初始化 COM 与日志"]
    B --> C["解析并校验 embedded metadata"]
    C --> D{"metadata 有效?"}
    D -->|否| D1["显示错误并退出"]
    D -->|是| E{"是否 --upgrade"}

    F --> G
    G --> H["准备并校验 GUI 资源"]
    H --> I["创建 GUIManager 窗口"]
```

## 安装服务主流程

```mermaid
flowchart TD
    A["ExecuteInstallService"] --> B["Preparing 状态"]
    B --> C{"是否已取消?"}
    C -->|是| C1["标记 Cancelled 并释放资源"]
    C -->|否| D["BuildInstallExecutionPlan"]
    D --> E{"计划构建成功?"}
    E -->|否| E1["写 install_failed 并返回失败"]
    E -->|是| F["ExecuteInstallPrecheck"]
    F --> G{"预检通过?"}
    G -->|否| G1["写 install_failed、释放 mutex、返回失败"]
    G -->|是| H["ExecuteInstallCleanup"]
    H --> I["旧版本清理完成或降级为 warning"]
    I --> J["写核心 installInfo state=installing"]
    J --> K["ExecuteInstallExecution"]
    K --> L{"文件与组件安装成功?"}
    L -->|否| L1["写 install_failed、释放 mutex、返回失败"]
    L -->|是| M["ExecuteInstallFinalization"]
    M --> N{"收尾成功?"}
    N -->|否| N1["写 install_failed、释放 mutex、返回失败"]
    N -->|是| O{"是否有可选组件失败?"}
    O -->|是| O1["整体返回失败并报告组件错误"]
    O -->|否| P{"是否需要重启替换锁定文件?"}
    P -->|是| P1["返回 RebootRequired"]
    P -->|否| Q["返回 Completed success=true"]
```

## 预检与升级清理

```mermaid
flowchart TD
    A["ExecuteInstallPrecheck"] --> B["检查磁盘空间"]
    B --> C["检查最低 Windows 版本"]
    C --> D["根据 appName 与 killProcesses 结束运行进程"]
    D --> E{"是否取消?"}
    E -->|是| E1["返回 cancelled"]
    E -->|否| F{"install.useMutex?"}

    F1 --> G

    H["ExecuteInstallCleanup"] --> I{"是否有旧安装?"}
    I -->|否| I1["跳过清理"]
    I -->|是| J{"新旧安装根是否相同?"}

    N --> O["cleanupUpgradeSystemArtifacts 清理 onUpgrade 注册表、卸载项、快捷方式、启动项、额外路径"]
```

## manifest 卸载执行

```mermaid
flowchart TD
    A["ExecuteUninstallFromContext"] --> B{"manifestReadable?"}
    B -->|是| C["uninstallFromManifest 读取 install.manifest.json"]
    B -->|否| C1["安全 fallback 卸载：仅清理安全安装目录内容与可确认系统痕迹"]
    C --> D["解析 appId、displayName、installDir、uninstallPath、files、cleanupRoots"]
    D --> E["结束 killProcesses 与 onUninstall.processes"]
    E --> F["写核心 installInfo state=uninstalling"]
    F --> G["回放 componentActions 中的卸载命令"]
    G --> H["删除启动项、快捷方式、registry values、legacyKeys、卸载注册表项"]
    H --> I["构建 UninstallCleanupTask"]
    C1 --> I
    I --> J["启动 --uninstall-cleanup-worker 并同步等待"]
    J --> K["worker 隔离安装根下直接子目录为 .mti_delete_pending_*"]
    K --> L["多线程删除 pending 子目录文件，跳过 reparse point"]
    L --> M["目录后序清理：直接 remove，非空跳过"]
    M --> N["低频 heartbeat，完成前主进程不返回"]
    N --> O["写核心 installInfo state=uninstalled"]
    O --> P{"当前进程是否 uninstall.exe?"}
    P -->|是| P1["scheduleSelfDeleteImmediate 或 scheduleSelfDelete"]
    P -->|否| Q["卸载完成"]
    P1 --> Q
```

## 关键规则

- 启动模式由入口二进制、`--silent` 和内部 worker 参数决定；`--upgrade` 只改变安装类型，不改变入口二进制。
- 安装权限策略由打包阶段写入 installer exe manifest；安装流程不再根据路径动态提权。
- `--cleanup-self`、`--upgrade-cleanup-worker`、`--uninstall-cleanup-worker` 都是内部参数，不参与普通用户模式选择。
- 覆盖/升级安装不 rename 整个安装根，只隔离安装根下直接子目录或本次 payload 涉及的直接子目录。
- 覆盖/升级安装与卸载都不使用 detached 后台删除；隔离出的 pending 子目录由 cleanup worker 同步删除，完成或超时后才继续后续流程。
- 清理 worker 的 heartbeat 采用低频覆盖写，常规逐文件成功项不写日志，不随文件数量线性追加日志 IO。
- 目录后序删除不先 `is_empty()`，直接 `remove()`；非空目录视为正常跳过，真实错误才记录 warning。
- 安装 manifest 的 `files` 优先来自解压阶段成功释放文件列表，只有该列表为空时才回退到递归扫描安装根。
- 安装包内目录最终落点由 metadata 中的 `layout.folders[].target` 固化，安装器不再根据旧式目录类型推导。
- 必选组件失败会中断安装；可选组件失败会继续执行，但最终结果标记为失败并返回组件错误。
- 若文件替换需要重启，安装服务返回 `RebootRequired`，不把结果当作普通成功。
