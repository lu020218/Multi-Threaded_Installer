# 安装器流程图

本文档描述当前 v3 manifest 驱动的安装、覆盖/升级和卸载流程。

## 启动分发

```mermaid
flowchart TD
    A["启动 installer.exe / uninstall.exe"] --> B["BuildLaunchContextFromCommandLine"]
    B --> C{"隐藏 worker 参数"}
    C -->|清理 worker| C1["执行同步清理任务"]
    C -->|否| D{"uninstall 模式"}
    D -->|是| E["RunGui/RunSilentUninstallMode"]
    D -->|否| F{"--silent"}
    F -->|是| F1["RunSilentInstallLikeMode"]
    F -->|否| F2["RunGuiInstallLikeMode"]
```

## 安装计划

```mermaid
flowchart TD
    A["读取内嵌 PackageManifest"] --> B["投影为运行期 metadata"]
    B --> C{"--upgrade"}
    C -->|是| D["通过 installer.installState.detect 主来源/legacy 来源发现旧安装目录"]
    D --> E{"旧 manifest 可读且有历史选项"}
    E -->|否| E1["升级失败退出"]
    E -->|是| F["固定旧安装目录和历史选项"]
    C -->|否| G["按 CLI/GUI/defaultDir 解析目标目录"]
    G --> H["通过 installer.installState.detect 主来源/legacy 来源判断是否覆盖安装"]
    F --> I["BuildInstallExecutionPlan"]
    H --> I
```

## 安装执行

```mermaid
flowchart TD
    A["准备安装"] --> B["写 installState=installing"]
    B --> C["执行预检查、磁盘检查、互斥量"]
    C --> D{"存在旧版本"}
    D -->|是| E["按旧 manifest files 清理旧文件"]
    D -->|否| F["跳过旧版本清理"]
    E --> G["如 manifest 缺失，按 missingManifestFallback 决定是否安全 fallback"]
    F --> H["释放 payload files"]
    G --> H
    H --> I["执行组件 install action"]
    I --> J["写 installer.registry.write"]
    J --> K["创建快捷方式、启动项、系统卸载项"]
    K --> L["写 installState=installed"]
    L --> M["写本地 v3 install.manifest.json 快照"]
```

安装失败路径会写 `installState=install_failed`，然后返回失败状态。

## Payload 释放

```mermaid
flowchart TD
    A["读取 manifest.payload.folders"] --> B["按组件选择过滤 payload"]
    B --> C["解析 payload.target"]
    C --> D["解压 tar stream 到目标目录"]
    D --> E["记录成功释放文件列表"]
    E --> F["安装收尾写入 manifest payload.files"]
```

释放成功文件列表直接用于 `install.manifest.json`，避免安装收尾再次扫描整个安装目录。

## 本地 manifest 快照

```mermaid
flowchart TD
    A["安装完成"] --> B["写 app 快照"]
    B --> C["写 installer.installState"]
    C --> D["写 installer.payload.files 和 selected components"]
    D --> E["写实际 defaults 选择"]
    E --> F["写实际 shortcut/startup/systemUninstallEntry"]
    F --> G["写 installer.installState.detect 和 cleanup policy"]
```

卸载优先消费该快照；当前安装包 metadata 不再作为 manifest 可读卸载的主逻辑来源。

## 卸载流程

```mermaid
flowchart TD
    A["Run uninstall mode"] --> B["ResolveUninstallContext"]
    B --> C{"显式 --uninstall-manifest 或本地 manifest 可读"}
    C -->|是| D["读取 v3 manifest 快照"]
    D --> E{"v3 必需字段完整"}
    E -->|否| E1["卸载失败，不做目录级 fallback"]
    E -->|是| F["按 manifest 执行卸载"]
    C -->|否| G["通过 installer.installState.detect 主来源/legacy 来源发现安装目录"]
    G --> H{"missingManifestFallback == safeDirectoryFallback 且目录安全"}
    H -->|否| H1["卸载失败或仅清理可确认痕迹"]
    H -->|是| I["安全降级卸载"]
```

## Manifest 卸载

```mermaid
flowchart TD
    A["关闭 killBeforeUninstall 进程"] --> B["执行组件 uninstall action"]
    B --> C["按 manifest payload.files 同步多线程删除文件"]
    C --> D["清理空目录和 cleanup.paths"]
    D --> E["按 installState cleanup mode 处理 registry/file stores"]
    E --> F["清理实际 shortcut/startup/systemUninstallEntry"]
    F --> G["清理 registry.deleteKeys/deleteValues 和 legacy 痕迹"]
    G --> H["调度 uninstall.exe 自删除"]
```

卸载完成前同步等待清理结束，不使用后台 detached 删除。
