# 打包器流程图

本文档描述当前 `packager.exe` v3 主流程。公开配置只支持 `schemaVersion: 3`，旧 schema 在打包阶段直接失败。

## 主流程

```mermaid
flowchart TD
    A["启动 packager.exe"] --> B["解析 --input/--config/--output"]
    B --> C{"是否 help"}
    C -->|是| C1["输出帮助并退出"]
    C -->|否| D{"三路径是否完整"}
    D -->|否| D1["报错退出"]
    D -->|是| E["校验 input/config/output 父目录"]
    E --> F["从 config 目录加载 packager.yaml/yml"]
    F --> G{"schemaVersion == 3"}
    G -->|否| G1["Unsupported schemaVersion"]
    G -->|是| H["解析 app/package/installer/uninstaller"]
    H --> I["校验 payload、组件、installState、权限策略"]
    I --> J["扫描 installer.payload[].source"]
    J --> K["按 payload folder 压缩"]
    K --> L["PackageManifestBuilder 从 v3 配置构建 manifest"]
    L --> M["SerializePackageManifest"]
    M --> N["写 installer execution level、icon、version info"]
    N --> O["嵌入 config/resources 与 uninstaller 模板"]
    O --> P["输出自解压 installer exe"]
```

## 配置加载与校验

```mermaid
flowchart TD
    A["ConfigurationManager.initialize(inputDir, configDir)"] --> B["ConfigurationLoader.loadConfiguration(configDir)"]
    B --> C{"packager.yaml 或 packager.yml 存在"}
    C -->|否| C1["配置加载失败"]
    C -->|是| D["YAML 转 JSON"]
    D --> E{"schemaVersion == 3"}
    E -->|否| E1["配置加载失败"]
    E -->|是| F["ParseV3App / Package / Installer / Uninstaller"]
    F --> G["ConfigurationValidator.validate"]
    G --> H{"校验通过"}
    H -->|否| H1["聚合错误到 lastError"]
    H -->|是| I["返回 PackagerConfiguration"]
```

关键规则：
- `app.id/name/version` 必填。
- `installer.defaultDir` 必填。
- `installer.payload[].id/source/target` 必填且 id 唯一。
- `installer.components[].payload[]` 必须引用已声明 payload id。
- `installer.installState.registries[]` 与 `installer.installState.files[]` 支持多个 store 和自定义 values。
- `installer.requireAdmin=false` 时拒绝 Program Files、HKLM 写入、machine/both 系统卸载项等管理员场景。

## Payload 扫描与 target 固化

```mermaid
flowchart TD
    A["读取 installer.payload[]"] --> B["source 相对 --input 解析"]
    B --> C{"source 目录存在"}
    C -->|否| C1["校验失败"]
    C -->|是| D["生成 FolderInfo"]
    D --> E["FolderInfo.id = payload.id"]
    E --> F["FolderInfo.targetPath = payload.target"]
    F --> G["压缩与 manifest 均使用该 target"]
```

安装器执行时直接读取 manifest 中的 payload target，不再按目录类型推导安装落点。

## 压缩流程

```mermaid
flowchart TD
    A["Resolve compression policy"] --> B["按 payload folder 创建压缩任务"]
    B --> C{"folder 数量 > 1"}
    C -->|否| D["顺序压缩"]
    C -->|是| E["多 worker 压缩"]
    D --> F["CompressionModule.compressFolder"]
    E --> F
    F --> G{"压缩成功"}
    G -->|否| G1["记录失败并退出"]
    G -->|是| H["生成 CompressionResult"]
    H --> I["包含 fileIndex、offset、size、checksum、algorithm"]
```

## Manifest 生成与输出协议

```mermaid
flowchart TD
    A["PackageManifestBuilder.build"] --> B["写 identity(app)"]
    B --> C["写 install policy(installer)"]
    C --> D["写 payload manifest"]
    D --> E["写 component manifest"]
    E --> F["写 ui manifest"]
    F --> G["写 uninstaller policy"]
    G --> H["SerializePackageManifest section codec"]
    H --> I["写 installer template"]
    I --> J["写 serialized manifest"]
    J --> K["写 compressed payload blocks"]
    K --> L["写 DataLocator 与尾部 magic"]
```

最终布局：

```text
[installer template + embedded UI resources + embedded uninstaller]
[sectioned package manifest]
[compressed payload blocks]
[DataLocator]
[end magic]
```

## 模板与资源来源

```mermaid
flowchart TD
    A["packager 所在目录"] --> B["installer/uninstaller 模板"]
    A --> C["DuiLib.dll 可选复制"]
    D["--config 目录"] --> E["packager.yaml/yml"]
    D --> F["resources/"]
    D --> G["app.icon 相对路径"]
    H["--input 目录"] --> I["installer.payload[].source"]
```
