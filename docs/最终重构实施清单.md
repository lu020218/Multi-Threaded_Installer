# 最终重构实施清单

本文档用于固化安装器进一步收敛后的最终重构方案，并记录当前实施状态。

## 目标

本轮重构的业务目标已经收口为以下规则：

- 启动模式只保留：
  - 图形安装
  - 图形卸载
  - 静默安装
  - 静默卸载
- 安装模式只保留：
  - `FreshInstall`
  - `OverwriteInstall`
- 是否进入覆盖安装，只通过 `lifecycle.cleanup.onUpgrade.installRoots` 发现当前用户已安装实例来决定
- 静默安装只允许：
  - 未安装时执行全新安装
  - 当前安装包版本高于已安装版本时执行覆盖安装
  - 同版本或低版本时直接退出

## 核心设计约束

### 1. 启动模式最小化

外部可见启动模式固定为：

- `InstallGui`
- `InstallSilent`
- `UninstallGui`
- `UninstallSilent`

删除：

- `RepairGui`
- `RepairSilent`

说明：

- `--cleanup-self` 仍可作为卸载后的内部自删除辅助参数存在
- 但它不再属于正式启动模式模型

### 2. 安装模式最小化

安装执行模式固定为：

- `FreshInstall`
- `OverwriteInstall`

删除：

- `Repair`
- `UpgradeMigration`

### 3. 已安装实例发现来源唯一化

旧版本或当前用户已安装实例的发现来源只允许来自：

- `lifecycle.cleanup.onUpgrade.installRoots`

明确禁止：

- 通过 `install.installInfo.path + installDir.key` 反查是否已安装

职责划分：

- `cleanup.onUpgrade.installRoots`：发现已有安装实例
- `install.installInfo`：写当前版本核心安装信息

### 4. 静默安装版本门禁

静默安装规则固定为：

- 未发现已安装实例：允许静默全新安装
- 发现已安装实例且 `packageVersion > installedVersion`：允许静默覆盖安装
- 发现已安装实例且 `packageVersion <= installedVersion`：拒绝安装并退出

## 当前判定规则

### 安装模式判定

- 遍历 `cleanup.onUpgrade.installRoots`
- 发现有效安装目录和 manifest：`OverwriteInstall`
- 未发现：`FreshInstall`

### 静默安装判定

- 未发现已安装实例：允许静默安装
- 发现已安装实例且当前包版本更高：允许静默覆盖安装
- 发现已安装实例且当前包版本不更高：拒绝静默安装

### 卸载判定

- 卸载面向当前用户当前安装实例
- manifest 定位优先使用本地 manifest，其次使用 `installRoots` 发现结果
